## compress_numbers

```python
def compress_numbers(numbers):
    result = []
    for value in numbers:
        if not result or result[-1] != value:
            result.append(value)
    return result
```

`[1, 1, 2, 2, 3] → [1, 2, 3]`
`[0, 0, 1, 1, 0] → [0, 1, 0]` — дубликаты удаляются только подряд идущие.

Сложность: O(n) по времени, O(n) по памяти. Входной список не изменяется.

## Что покрыто тестами

- пустой массив, один элемент, все элементы равны
- отсутствие дубликатов, чередующиеся значения
- дубликаты в начале и в конце
- отрицательные числа, дробные числа, `0.0` / `-0.0`
- особенность Python: `True == 1` (задокументировано тестом)
- большой массив на 100 000 элементов
- контракт: возвращается новый список, входной не мутируется
- параметризованный набор кейсов с читаемыми `ids`

## Известные ограничения

- Подряд идущие `float('nan')` не схлопываются, потому что `nan != nan`.
- Для работы нужен итерируемый объект; тип возврата всегда `list`.
